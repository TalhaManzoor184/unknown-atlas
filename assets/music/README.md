# Background music

Drop licensed tracks here (`.mp3`, `.wav`, `.m4a`, `.ogg`). The pipeline picks one per video and ducks it under the narration.

Use only music you're allowed to monetize:
- **YouTube Audio Library** (YouTube Studio → Audio Library). Filter by *Attribution not required* to keep descriptions clean.
- Dark/ambient/cinematic moods work best (search "ambient", "cinematic", "suspense").

If this folder is empty, videos render with narration only.
