# Background music

The `atlas-*.mp3` beds are **original music generated by `scripts/make_music.py`** (pure synthesis, no samples),
so they are free to monetize with no attribution and no Content ID risk.

| Track | Mood | Used for (topic pillar) |
|---|---|---|
| `atlas-unknown.mp3` | dark minor drift | mysteries, history |
| `atlas-tension.mp3` | low pulse, suspense | mysteries, history |
| `atlas-discovery.mp3` | warm, hopeful | science, history, space |
| `atlas-deep-field.mp3` | airy, shimmering | space & strange places, science |

The renderer picks a track that matches the topic's pillar, ducks it under the narration, and fades it in and out.
Volume: `music.volume` in `config.yaml`.

You can add your own tracks here too, for example from the YouTube Audio Library (choose *Attribution not required*).
Any file whose name doesn't start with a mood prefix is used as a general fallback.
To regenerate or vary the built-in beds, change the chords or seed in `scripts/make_music.py` and run it again.
